# Contributing

Thanks for helping improve the CKB Developer Onboarding Guide.

This project needs practical feedback from people who try the guide on real machines.

## Useful Ways To Help

- Test the guide on Windows, Linux, or another macOS machine.
- Review whether the beginner path is clear.
- Check technical accuracy of CKB, RPC, node, and indexer steps.
- Share real setup failures so the troubleshooting section can improve.

## Testing The Guide

Start here:

- `docs/quick-start.md`
- `docs/branching-paths.md`
- `docs/how-to-verify.md`

For structured testing, use:

- `docs/contributing/test-the-guide.md`
- `docs/third-party-reproducibility.md`

## Reporting Results

When reporting a test result, include:

- operating system and version
- terminal shell
- path tested: Path A, Path B, or Path C
- command output or error
- first confusing step, if any
- suggested documentation change

Please remove personal paths, usernames, tokens, and private project names before posting logs.

## Pull Requests

Small documentation fixes are welcome.

Prefer focused changes:

- one issue per PR
- clear before/after wording
- no unrelated formatting churn
